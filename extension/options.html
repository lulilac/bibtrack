bibtrack server

A local server opens inside the toolbar popup; a remote one does too, falling back to its own window if the browser has no password for it yet.

Tick already-saved pages

Puts a green tick on the toolbar icon when the page you are on is already in your library. It needs permission to read tab addresses and to reach your server in the background — your server only, asked for when you turn this on.

Sign-in for the tick (optional)

Only needed if your server asks for a password and the tick never appears. Stored unencrypted in this browser's add-on storage.
